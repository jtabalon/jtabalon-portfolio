# Repository guidance

## Product context

Read `CONTEXT.md` and `docs/site-direction.md` before changing the site's public narrative, information architecture, or terminology.

## Decisions

Read relevant records under `docs/adr/` before changing a documented architectural decision. Surface conflicts rather than silently overriding them.

## Issue tracker

Use GitHub Issues for issues and specifications. See `docs/agents/issue-tracker.md` and `docs/agents/triage-labels.md`.
