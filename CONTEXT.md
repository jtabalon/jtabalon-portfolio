# Personal Site

This context defines the public portfolio's professional communication and interaction language. It keeps content hierarchy and motion decisions aligned around a calm, credible experience for hiring managers.

## Language

**Primary contact action**:
The visually dominant invitation to email Joseph about a senior production-ML role. It appears in both Hero and Contact with the label “Email me.”
_Avoid_: CTA, primary button

**Secondary link**:
A navigation, evidence, professional-profile, or utility link that remains visually subordinate to the Primary contact action.
_Avoid_: Secondary action, alternate CTA

**Editorial motion**:
Restrained, purposeful motion that provides interaction feedback or softens the homepage’s initial arrival without delaying or moving reading content. It excludes scroll reveals, parallax, pulsing, and choreographed text entrances.
_Avoid_: Animation system, decorative motion

**Search identity**:
The name, role, and positioning statement presented to search engines for the canonical site: “Joseph Tabalon | Senior Data Scientist” and the existing production-ML description.
_Avoid_: SEO copy, search snippet

**Social preview**:
The restrained editorial card shown when the canonical site is shared: warm canvas, Joseph’s portrait, name, role, and “Machine learning that holds up beyond the notebook.”
_Avoid_: Social card, link thumbnail

**Public identity**:
The minimal facts intentionally exposed as machine-readable identity data: Joseph’s name, canonical site, role, portrait, LinkedIn profile, and GitHub profile.
_Avoid_: Person schema, profile metadata

**Canonical site**:
The authoritative public version of the portfolio at https://www.josephtabalonjr.com. Other host variants should lead to this address without competing for indexing.
_Avoid_: Production URL, primary domain

**Indexable page**:
A public portfolio page intended to appear in search results. The homepage is currently the only Indexable page; anchors, error pages, and diagnostic routes are not separate entries.
_Avoid_: Crawlable route, sitemap entry

**Discovery policy**:
The portfolio’s public stance of allowing compliant search, sharing, and AI-assisted discovery services while listing only Indexable pages for indexing.
_Avoid_: Robots policy, crawler configuration
