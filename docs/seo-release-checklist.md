# SEO release checklist

Complete these checks after deploying the canonical site:

- Confirm `https://www.josephtabalonjr.com/` returns the homepage and its initial HTML contains the Search identity, Social preview metadata, and Public identity.
- Confirm `https://josephtabalonjr.com/` permanently redirects to the Canonical site with status `308` while preserving the requested path.
- Confirm `/robots.txt`, `/sitemap.xml`, `/social-preview.png`, and `/joseph-tabalon.png` are publicly available from the Canonical site.
- Validate the homepage with [Google Rich Results Test](https://search.google.com/test/rich-results).
- In Google Search Console, verify ownership, submit `https://www.josephtabalonjr.com/sitemap.xml`, inspect the homepage, and request indexing.
- Refresh the cached Social preview with [LinkedIn Post Inspector](https://www.linkedin.com/post-inspector/).
