# Triage labels

Use only labels that currently exist in this repository.

| Label | Use |
| --- | --- |
| `ready-for-agent` | The issue is fully specified and can be implemented without another product decision. |
| `enhancement` | New or improved site capability or content. |
| `bug` | Existing behavior is incorrect. |
| `documentation` | Documentation-only work. |
| `question` | More information or a decision is required. |
| `good first issue` | A bounded task suitable for a new contributor. |
| `help wanted` | Additional contributor attention is useful. |
| `duplicate` | Another issue already tracks the same outcome. |
| `invalid` | The request is not actionable as filed. |
| `wontfix` | The repository will not pursue the request. |

Do not refer to `needs-triage`, `needs-info`, or `ready-for-human` as configured labels unless they are added to GitHub first.
